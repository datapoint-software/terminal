# Autopilot notes

Decisions taken while the product owner was away, for review. Each one either follows the documented specification, or works around something the specification didn't foresee; the second kind is marked **Deviation**. Settled points are also recorded where they belong (product.md, engineering.md); this file is the list to review, newest last.

| # | Date | Decision | Why | Kind |
| --- | --- | --- | --- | --- |
| 1 | 2026-11-06 | Tests reference `xunit.v3.mtp-v2` 3.2.2 rather than `xunit.v3` 3.2.2. | `xunit.v3` 3.2.x brings Microsoft.Testing.Platform 1, which crashes with the current code coverage extension (built for version 2); the `mtp-v2` package is the same xUnit on version 2. Recorded in engineering.md. | Deviation |
| 2 | 2026-11-06 | Test projects are created with their first tests, not all up front. | Microsoft.Testing.Platform fails a run when a test project has no tests (exit code 8). Recorded in engineering.md. | Clarification |
| 3 | 2026-11-06 | `.editorconfig` asks for UTF-8 without a byte order mark, overriding the dotnet/docs base. | No tool we use needs one, and they show up as noise in diffs. Marked with a comment in the file. | Clarification |
| 4 | 2026-11-06 | The third-party notices generator (`tools/`) is postponed until the first release build; until then each package's license is checked by hand against the allowlist when it's added. | Building it now would delay the core work, and nothing is distributed yet. Packages so far: Avalonia, CommunityToolkit.Mvvm, Microsoft.Extensions.* (MIT), BouncyCastle (MIT), Porta.Pty (MIT), xUnit (Apache-2.0), analyzers (MIT/Apache-2.0, not distributed). | Deviation |
| 5 | 2026-11-06 | SSH security rules researched and adopted (engineering decision 16), including leaving out compression, Diffie-Hellman group exchange, SHA-1 key exchange, SSHFP and X11 forwarding. | Each answers a published attack on SSH clients; none of these features was in the plan's order of work. `ProxyCommand`, `Match exec` and `LocalCommand` are kept, since users' configurations rely on them, with the safeguards listed. | Clarification |
| 6 | 2026-11-06 | Product decision 84: accepting host keys is only ever the user's, and the agent changing local SSH configuration, `known_hosts` or keys always asks, even in Auto. | Auto was defined as never asking; these few actions decide which machines are trusted, so a prompt injection reaching them would outlast the task. | Deviation |
| 7 | 2026-11-06 | First iteration of the screen model: scrollback is a list of rows capped by count (10,000 by default), not yet the ring of fixed-size pages capped in bytes; resizing truncates rather than reflows; graphemes join only combining marks (no UAX #29 clustering or mode 2027 widening yet); styles are stored in each cell rather than once per page. | Gets a correct, tested model working end to end before optimizing; engineering.md's design stays the target, to reach once benchmarks exist. | Deviation |
| 8 | 2026-11-06 | Width tables are generated from Unicode 18.0 by `tools/unicode/generate_width_table.py`: East Asian Wide and Fullwidth, plus `Emoji_Presentation`, are two cells; nonspacing, enclosing and format characters (except the soft hyphen) and Hangul medial and final jamo are zero. | Follows engineering.md's "our own Unicode tables"; these are the rules wcwidth implementations and Ghostty use. | Clarification |
