# European Portuguese glossary

The terms Datapoint Terminal uses in European Portuguese (product decision 150), so the translation reads the same everywhere. Follow Portugal's spelling under the 1990 Orthographic Agreement and its vocabulary, not Brazil's. When a term isn't here, use the one Portuguese versions of macOS, Windows and common developer tools use, and add it.

## Style

- **Address the user formally and impersonally,** as Portuguese software does: infinitives and imperatives in the third person (*Escolha um fornecedor*, *Guardar*), never *tu*.
- **Buttons are infinitives:** *Guardar*, *Cancelar*, *Abrir*, *Executar*.
- **Keep sentence case** as in English: only the first word and proper names in capitals.
- **Keep placeholders** (`{0}`, `{1}`) and keyboard shortcuts exactly as they are.
- **Leave untranslated:** product, company and provider names (Datapoint Terminal, Anthropic, OpenAI, Claude, GPT), commands, file names, protocol names (SSH, HTTP), and terms of art Portuguese users read in English (*prompt*, *shell*, *host*, *token*, *commit*).
